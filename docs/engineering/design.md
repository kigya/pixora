# Дизайн и экранные состояния

Статус 0.8.0: актуальное визуальное направление реализовано в React Native-компонентах; финальная приёмка интерфейса на физических устройствах ещё не завершена. Отдельный утверждённый макет Figma в этом документе не фиксируется. Поведение и ограничения продукта определяет [основной PRD](../PRD.md), изменения 0.8 трассируются в [workflow PRD](../product/prd.md).

## Визуальная система

- Темы: системная, светлая и тёмная. Общие цветовые роли находятся в `src/ui/theme.tsx`; основные поверхности и текст имеют отдельные токены, цвет акцента используется для действия и текущего выбора. Тёмная базовая поверхность — `#09090B`, карточка — `#18181B`, основной текст — `#FAFAFA`, акцент — `#7C3AED`; светлая тема задаёт собственные значения.
- Текст использует системный шрифт. Стили экранов совместно создаются через `createStyles` с параметром RTL. Компоненты действий и выборов имеют доступные названия и крупные зоны нажатия; принятый ориентир — не меньше 48 dp.
- Основной фон и карточки используют простые поверхности, границы и умеренные скругления. Нет WebView, видео, тяжёлых шейдеров или декоративной анимации.
- React Navigation отключает переход при включённом системном Reduce Motion. Анимации раскрытия используют opacity/transform и `ReduceMotion.System`.

## Маршруты и ключевые состояния

`AppNavigation` показывает ожидание загрузки настроек, затем выбирает начальный маршрут по `languageChosen`: на свежей установке — выбор языка, далее — главная. Основные маршруты: `LanguageOnboarding`, `Home`, `Settings`, `Feedback`.

Главный сценарий состоит из выбора исходного изображения, настройки режима/масштаба, при необходимости подтверждения подготовки большой копии, обработки, сравнения результата и экспорта. Исходник не перезаписывается. Рекомендация режима — локальная подсказка с явным действием пользователя; приложение не меняет выбранный режим автоматически.

| Состояние | Отображение и поведение |
|---|---|
| Загрузка настроек | Центрированный индикатор до показа навигации. |
| Пустая главная | Краткое предложение выбрать изображение; системный picker открывается явным действием. Отмена выбора не превращается в ошибку. |
| Выбранное изображение | Превью сохраняет пропорции; доступен выбор режима и 2×/4×. Для уменьшения большого исходника до обработки требуется отдельное подтверждение с размерами. |
| Обработка | Показаны текущая работа, фактический прогресс/время и действие отмены. Android сообщает о длительной задаче через системное уведомление; iOS-предупреждение говорит о возможном прерывании и ручном повторе. |
| Результат | Сравнение «до/после», размеры, время и действия экспорта/отправки. Повторное сохранение уже существующего формата не создаёт ещё один экспорт того же результата. |
| Ошибка | Понятный локализованный текст; для ошибки сохранения/отправки сохранённый пользователем текст остаётся доступен для повторного действия. |
| Настройки и поддержка | Язык, тема, формат, лимит рабочих файлов, разрешения/диагностика и форма связи. Адрес для ответа в форме необязателен. |

Эти состояния описывают реализуемый UI, а не утверждают физическую проверку каждого перехода. Подробные продуктовые правила находятся в основном PRD.

## Адаптация и доступность

`src/ui/layout.tsx` рассчитывает доступную область с учётом safe area и native window-layout/hinge данных. На узком окне используется одна колонка; двухколоночная компоновка включается для ширины от 720 dp, если масштаб шрифта меньше 1.5. При увеличенном шрифте контент остаётся прокручиваемым. RTL меняет направление рядов и навигационных символов, сохраняя LTR для размеров и чисел.

Первый выбор языка — самостоятельный первый маршрут, а не обязательный tutorial. При возврате на системный язык приложение использует текущую системную локаль; ручной выбор применяется немедленно. Реестр включает 34 локали и legacy `pt` для миграции в `pt-BR`. Арабский, фарси, урду и иврит отмечены RTL. Статусы и ограничения перевода отражены в [реестре локалей](../product/locales.json) и [отчёте покрытия](../agent-reports/workflow-parity.md).

Пикер, справка, диалоги и действия должны работать без обязательного drag-жеста и иметь доступные названия. Сравнение имеет отдельные кнопки до/после/сравнить. Проверки шрифта 200%, TalkBack/VoiceOver, реальных hinge-устройств и полного набора планшетов остаются отдельными приёмочными сценариями; их нельзя считать пройденными по наличию responsive-кода.

## Иконка и движение

В репозитории есть брендовые исходники в `assets/brand/`; экспортные форматы и результаты превью считаются подтверждёнными только соответствующим build/store handoff, не этим описанием. Не добавлять анимации, которые конкурируют с прогрессом длительного AI-расчёта. Соблюдать системное ограничение движения и сохранять смысл без анимации.
