# Pixora 0.9 UX correction and bounded verification

This revision implements the owner-approved 24 October 2026 UX and result-rating flow on the existing Expo migration branch. It is a feature/APK delivery, not a completed whole-app release handoff.

## Implemented behavior

- One Aurora launch composition with only the logo; its 1500 ms minimum starts after the visible layout/frame handoff. Android 12+ saves explicit light/dark launch themes for subsequent cold starts and restores system-following resources for System. The platform may show its compulsory plain launch window before application code runs. A real Xiaomi recording confirms matching light backgrounds after fixing the API call to use `Activity.splashScreen`; a null system-service lookup had prevented the override.
- Three custom vector onboarding compositions, horizontal swipes only, passive examples, a separated page indicator, reduced-motion and background/invisible-page handling, skip and Settings replay.
- Branded Segment Bar controls for processing kind, scale and export format. Text-first collapsed model cards retain independent selection. Quality is on the left and Speed on the right. Only one predicted result size is shown.
- Recreate retains the imported photo as its working image. Its separate illustration uses the same cat in degraded and clean reference photographs; the manifest explicitly identifies the clean reference as illustrative, not a generated result.
- Inline searchable language selection, direct System/Light/Dark choices, repaired telemetry layout and dialog gesture roots, real disjoint storage categories and cache-only cleanup. The single AI detail notice belongs to active processing.
- A dismissible star dialog after a new internal successful result, never a restored/failed/cancelled result. The actual display is persisted; another prompt requires a new success and at least five minutes. No thumbs voting. Confirmed 1–4 stars open support with the rating; 5 opens Google Play with an explicit Play package and HTTPS fallback. No review or message is automatically submitted.
- One native rating event after durable persistence, with allowlisted technical image/job parameters and immutable enhancement recommendation context. Recreate does not inherit an enhancement recommendation. Saved Analytics opt-outs apply. Images, names, URIs, EXIF, prompt text and support content remain excluded.
- Stale prompt, submission and store callbacks cannot navigate or re-enable a different job after blur, background, close or job replacement.

Selective store routing was explicitly chosen by the owner after discussion of its policy risk. Implementation is not evidence of Google Play policy compliance.

## Mode-switch performance limit

The initial installed UI measured 42/86 janky frames in a bounded eight-switch trace. The revised text-first/Expo-image UI measured 37/227 (16.30%), but its p90 was 200 ms versus the old 150 ms, so this is mixed evidence rather than a smoothness pass. A retained-panel candidate measured 37/201 (18.41%) with p90 250 ms and was reverted. No memoization or extra UI state was retained on an unproven performance claim. Native rendering latency on this phone remains a separate performance acceptance limit.
