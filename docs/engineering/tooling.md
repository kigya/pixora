# Инструменты и воспроизводимость

Локальная библиотека указана в ignored .p-build-app/tooling.json. Публичные инструкции не зависят от абсолютного пути владельца.

Записать зафиксированные версии RN/Node/JDK/Xcode/package manager, lockfile, test/build команды, необходимые проектные MCP и бесплатные ограничения. Не выполнять глобальную установку или включать платные сервисы. Список скиллов/лицензий/commit — в локальном registry и отчёте установки; для других разработчиков описать, как использовать публичные docs без этой локальной библиотеки.
