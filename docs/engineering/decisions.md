# Решения 16.10.2026

- ADR-801: рекомендации — локальные эвристики, не новая модель; только предложение с кнопкой, без автоприменения. Прямой выбор пользователя.
- ADR-802: включить полную iOS-реализацию и привести поведение к P Build App.
- ADR-803: сохранить предоставленные примеры; пользователь подтвердил права на публичное распространение. Они остаются примерами, не доказательством результата модели.
- ADR-804: iOS использует доступный фон и корректное прерывание при expiration, затем повтор с начала.
- ADR-805: физический Samsung SM-S916B заменяет Xiaomi во всех приёмочных gate; legacy ID gate может оставаться xiaomi-* с явно указанным override.
- ADR-806: публичный kigya/pixora; root единолично управляет Git; task PR в release/0.8.0, один итоговый squash в main, CI только main push.
- ADR-807: docs/PRD.md остаётся основной спецификацией; workflow PRD содержит изменения и FEAT-ID. Исторические отчёты не считаются свежими проверками.
