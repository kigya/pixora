# Решения 16.10.2026

- ADR-801: рекомендации — локальные эвристики, не новая модель; только предложение с кнопкой, без автоприменения. Прямой выбор пользователя.
- ADR-802: включить полную iOS-реализацию и привести поведение к P Build App.
- ADR-803: сохранить предоставленные примеры; пользователь подтвердил права на публичное распространение. Они остаются примерами, не доказательством результата модели.
- ADR-804: iOS использует доступный фон и корректное прерывание при expiration, затем повтор с начала.
- ADR-805: физический Samsung SM-S916B заменяет Xiaomi во всех приёмочных gate; legacy ID gate может оставаться xiaomi-* с явно указанным override.
- ADR-806: публичный kigya/pixora; root единолично управляет Git; task PR в release/0.8.0, один итоговый squash в main, CI только main push.
- ADR-807: docs/PRD.md остаётся основной спецификацией; workflow PRD содержит изменения и FEAT-ID. Исторические отчёты не считаются свежими проверками.

## Ручное ревью пользователя — уточнение 16.10.2026

- ADR-808: пользователь самостоятельно проверил приложение и сообщил «все ок». После Apply suggestion карточка скрывается для текущего изображения; новое изображение получает новое предложение.
- ADR-809: Feedback/Having Issues использует такую же симметричную панель с центрированным заголовком, как Privacy/Licenses. Дублирующая кнопка Having Issues внутри формы удалена. Применено общее предпочтение LESSON-0001; сама общая база остаётся вне репозитория.
- ADR-810: новое явное указание заменяет прежнее default-OFF/opt-in правило 0.8: Usage Analytics и Error Reports включены по умолчанию, приложение показывает информационное уведомление и позволяет отключить их независимо в Settings. Уже явно сохранённые настройки не перезаписываются. Положение switch обновляется сразу, записи в native storage выполняются последовательно.
- ADR-811: анимация логотипа на системном экране запуска Android12+ через AnimatedVectorDrawable; launcher icon зависит от системного лаунчера.
- ADR-812: по прямому указанию пользователя дальнейшие автоматические и ручные тесты приложения остановлены. Выполняются изменения, сборка release-mode с тестовой подписью и установка на Samsung, затем ожидается ручное подтверждение пользователя. Предыдущие проверки относятся к прежнему исходному состоянию; новый код не получает старые PASS/100% по наследству. Main merge/готовность полного handoff не подтверждаются до ручной приёмки и согласования оставшихся обязательных проверок.

- ADR-813: по повторному ручному ревью splash удерживается до JS NavigationContainer.onReady после initial settings/session refresh и минимум1500ms; длительность animator отдельно1500ms. UI/JS-потоки не блокируются. LESSON-0002 хранится только в общей локальной базе. Пользователь подтвердил остальные правки и продолжение flow.

- ADR-814: после отдельного уточнения пользователь разрешил автоматические проверки и исправления без UI на Samsung. Установку нового релиза пока не выполнять. Предыдущий запрет тестов снят только в этой части; финальные strict coverage/security/build/CI проверяются автоматически. Физические UI/install не заменяются фиктивным PASS.
