# Матрица тестов

Статус: тесты ещё не созданы.

Для каждого TEST-ID: FEAT-ID/критерий PRD; что проверяет; уровень unit/component/native/E2E; вход/предусловия; ожидаемый результат; corner cases; path/команда; последний результат/commit; доказательства. Связать все критерии, не считать один test file полной проверкой функции.

Coverage: 100% собственного исполняемого JS/TS по строкам, statements, functions и branches; собственный native code отдельно с реальным измерителем. Генерация/зависимости/неизменённый scaffold исключаются явно. E2E покрытие не выражается этим процентом. Отсутствующая проверка остаётся блокером.
