# Pixora 0.8.0 — статус

Дата: 16.10.2026. Этап: реализация и интеграция 0.8.0.

База приложения импортирована через PR #1 в release/0.8.0. Рекомендации и пояснение подготовки фото прошли независимое ревью и включены через PR #2; Android debug с ними собран. Изолированная проверка рекомендаций: 163 Jest tests, 100% всех четырёх метрик JS/TS; C++ classifier 110/110 строк и 64/64 ветвей. Это не итоговая приёмка 0.8.0 и не доказательство точности классификации.

В работе: iOS CPU-порт, 34 языка и миграции согласий/настроек, нейтральный native review и optional feedback email, main-only CI и security checks. Независимое ревью выявило и направило на исправление ошибки privacy при неудачном opt-out и сохранении cooldown review. Свежие базовые Android JVM tests: 74/74; собственный Kotlin имеет пробелы покрытия (873/926 строк, 974/984 ветвей), поэтому native gate не пройден.

Target device: Samsung SM-S916B / Android 16 / API36; приватный serial остаётся только локально. Установка и сценарии текущей версии на Samsung, полные финальные проверки, iOS release build, Firebase delivery и CI текущего main ещё pending. Main пока содержит только технический bootstrap. Финальный main merge выполняется после локальной приёмки; публикация в stores и финальная подпись вне этого этапа.
