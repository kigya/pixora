# Pixora 0.8.1 — корректирующая приёмка

Дата: 16.10.2026. Функции сохраняются из согласованной версии 0.8; новых возможностей в 0.8.1 нет.

## GitHub и причина исправления

PR №13 был единственным squash версии 0.8.0 в main: `2ea2dd22db1b1f24bb67a8a5e160304c5b5d9851`. [CI 38955818843](https://github.com/kigya/pixora/actions/runs/38955818843) завершился ошибкой: setup-java v4 не принял формат версии JDK, а npm ci получил 404 для ошибочного URL text-table 0.3.0. По ADR-815 исправления проходят новый release/0.8.1 и task-ветку fix/081-ci-reproducibility, затем один итоговый PR. Неудачный запуск и история сохранены; CI работает только по main push.

Lockfile восстановлен по официальному registry; setup-java обновлён до immutable pin v6.1.0 с точным выбором JDK 21.0.12.1+1. Версия 0.8.1 / code 11 согласована в package, lock, Android и iOS project/generator. Чистая npm ci с пустым кэшем установила 995 пакетов. Проверены все 932 URL: единственный прежний 404 исправлен. Android autolinking вызывает локальный locked CLI через NODE_BINARY либо node из PATH, сохраняя стандартные cache inputs RN. Независимое ревью изменений не оставило замечаний.

## Автоматические проверки

JS: 168/168 тестов в 14 наборах, все четыре метрики покрытия 100%; TypeScript PASS, lint 0 ошибок. Kotlin b54: 111/111, 1062/1062 lines и 1106/1106 branches. iOS: 52/52, 607/607 lines и 794/794 branches. C++ и общий source-presence gate PASS; все требуемые метрики 100%. Android b55 APK/AAB и unsigned arm64 iOS 0.8.1(11) Release PASS. Подробности в coverage.md, build-report.md и отчётах агентов. Локальная приёмка 0.8.0 ранее достигла 100% покрытия и успешных Android/iOS Release builds; это не заменяет main CI и физическую проверку новой сборки.

## Действующие границы

ADR-814 разрешает автоматические тесты, сборки, CI и исправления. Новая установка на Samsung и дальнейшие UI-проверки отложены. Пользователь подтвердил остальные функции b44; новый splash 1500 ms не получает физический PASS по наследству.

Сохранены рекомендации с ручным Apply и скрытием карточки, объяснение подготовки 1024/Fast512, единые панели Feedback/Privacy/Licenses, default-ON notice с независимыми сохранёнными opt-outs, последовательные немерцающие switches и splash max(readiness, 1500 ms). LESSON-0001/0002 хранятся только в общей локальной базе Personal.

Локальные проверки и сборки завершены. Task PR №15 передаёт исправления в release/0.8.1, затем один итоговый squash в main и проверка CI/CodeQL на фактическом SHA. Физические и service gates остаются явно отложенными; полная готовность к публикации не объявляется. Финальная подпись, GitHub Release, stores и billing вне Build App.
