# Приватность и согласие 0.8.0

Состояние: поведение реализуется; юридическая и store disclosure проверка остаются pending.

- AI inference, исходные изображения, результат, URI, имена файлов и рабочие пути остаются на устройстве. Они не передаются в Firebase или форму поддержки.
- Android применяет независимые сохранённые Analytics/Crashlytics switches до инициализации Firebase; iOS применяет эффективные значения на native startup. По решению пользователя от16.10.2026 отсутствие явного выбора означает оба значения ON с информационным уведомлением. Явные сохранённые отключения остаются OFF; при отказе Crashlytics удаляет неотправленные отчёты.
- Согласия Analytics и Crashlytics независимы, оба изначально выключены. Выбор отображается до включения любого из сборщиков. Отзыв выключателя останавливает будущий сбор соответствующего SDK; Remote Config работает независимо и не требует согласия на диагностику.
- Firebase получает только allow-list продуктовых событий и отчёты о сбоях согласно отдельному согласию. Код не добавляет изображения, URI, имена файлов, email, текст формы, постоянный ID пользователя или рекламный идентификатор в телеметрию. Crashlytics удаляет неотправленные отчёты при выключении.
- Форма поддержки отправляет только текст, необязательный адрес для ответа, версию приложения, нормализованную платформу (`android`/`ios`) и случайный ID запроса. Legacy-запрос без `platform` трактуется как Android; Apps Script включает платформу и версию в письмо. Протокол сохраняет поле `rating` со значением `0` для совместимости; пользовательскую оценку приложение не собирает. Отправка доступна отдельно от согласия на телеметрию. При недоступном endpoint есть явный переход в почтовое приложение; сообщение покидает устройство только после отправки пользователем.
- Для формы сохраняется исходная политика размера, rate limit, дневной квоты и idempotency. Apps Script отправляет письмо фиксированному адресу и задаёт Reply-To только при наличии валидного адреса.

Публичная privacy-policy и проверки Google Play Data Safety / Apple privacy disclosures не завершены. Не объявлять юридическую проверку пройденной.

Уточнение 16.10.2026: по явному решению владельца продукта Analytics/Crashlytics включены по умолчанию и сопровождаются информационным уведомлением. Независимые выключатели сохраняются; явно сохранённые отключения не перезаписываются. Это заменяет прежнее opt-in описание для текущей реализации0.8. Inference и изображения остаются локальными. Runtime-проверка новых defaults ожидает ручной приёмки пользователя.
