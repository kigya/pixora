# Workflow PRD 0.8.0

Основной источник поведения: [PRD](../PRD.md). Этот документ фиксирует согласованные изменения и их трассировку.

| ID | Требование и основание | Приёмка |
|---|---|---|
| FEAT-001 | Существующий импорт → офлайн AI → сравнение → экспорт; docs/PRD.md | Регрессионная матрица на Android и iOS |
| FEAT-801 | Локальная эвристическая рекомендация: фото→lite/quality, рисунок→art/quality, пиксельная сетка→pixel, неопределённость→lite. Прямой запрос пользователя 16.10.2026; эффективность — гипотеза | TEST-801: типы, неоднозначность, доступность, ошибки, гонки; только кнопка применения, без автосмены |
| FEAT-802 | Объяснить подготовку большой копии с реальными размерами, памятью/временем, неизменным оригиналом и возможной потерей деталей. Прямой запрос | TEST-802: разные пропорции, 2x/4x, Fast, отмена |
| FEAT-803 | Полный iOS-порт существующих возможностей, ncnn CPU, ограниченный фон. Прямой выбор пользователя | TEST-803: реальные inference/экспорт/отмена; Release без подписи |
| FEAT-804 | Analytics/Crashlytics включены по умолчанию с уведомлением и независимыми выключателями по уточнению ручного ревью 16.10.2026; нейтральные отзывы, optional email, R8 off. Пользователь выбрал правила скилла вместо прежних решений | TEST-804: cold start/upgrade/revoke/offline/RC/review |
| FEAT-805 | Первый выбор языка, native locale sync, сохранить текущие + pa/jv/gu/he, pt→pt-BR. Требование выбранного workflow, без удаления языков | TEST-805: 34 схемы, system/RTL/large text/restore |
| FEAT-806 | Публичный GitHub, task PR→release/0.8.0→один main merge; CI main-only. Прямой запрос | TEST-806: история PR, CI current HEAD, privacy/security |

Гипотеза FEAT-801: признаки контуров/текстуры/сетки помогают предложить полезный режим. Проверка: размеченный разрешённый корпус и контроль ложного Pixel Art; fallback — lite без заявления о распознанном типе. Технический PASS не доказывает рыночный спрос. Новые модели и облачная классификация исключены.

Уточнение пользователя после ручного ревью 16.10.2026: после применения рекомендация скрывается для текущего изображения; форма Feedback имеет центрированный заголовок как Privacy/Licenses и не содержит повторной кнопки Having Issues. Логотип анимируется при системном запуске Android12+. Последующее тестирование остановлено по прямому указанию; следующая точка приёмки — пользователь проверяет установленную release-mode сборку. Подробности ADR-808–812.
