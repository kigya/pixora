# Продуктовые показатели

Статус: требуется исследование.

Для каждой метрики: понятное определение; зачем измеряется; источник/формула; сегмент/период; ограничения; связанные события; тесты. MAU — Monthly Active Users, число активных пользователей за месяц. Не путать наличие события с измеренным успехом или прогнозом рынка.
