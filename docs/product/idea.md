# Pixora: improving the existing application

Approved 0.8.0 improves the existing app with a manually applied content-based local recommendation, clear large-image preparation, a full iOS implementation and public GitHub/PR/CI workflow. It continues the existing 0.7.2 Android product rather than creating a new app.

The product is free, without ads, paywalls or cloud AI. Physical acceptance uses Samsung SM-S916B instead of Xiaomi by explicit owner instruction.


On 2026-10-17 the owner approved a conservative recommendation revision: prefer content-appropriate existing Standard/Natural/Balanced/Art/Pixel profiles, reserve Lite for manual use or unavailable profiles, and retain offline processing with no new weights/dependencies. The owner accepted the signed Android release installed over USB and subsequently authorized source publication as 0.8.5 through the usual PR workflow, without additional checks.
