# Pixora: доработка существующего приложения

Пользователь просит реализовать согласованный план 0.8.0: локальная рекомендация режима по содержимому с применением кнопкой, понятное уменьшение больших изображений, полноценная iOS-часть, приведение к P Build App и публичный GitHub/PR/CI. Это продолжение существующего Android-продукта 0.7.2, не создание нового приложения.

Продукт бесплатен, без рекламы, paywall и облачного AI. Физическое устройство приёмки — Samsung SM-S916B по прямому указанию пользователя вместо Xiaomi.
