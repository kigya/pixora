# Pixora 0.8.0 — исследовательское основание

Это доработка работающего локального Android-инструмента, а не выбор новой идеи. Существование прямых офлайн-конкурентов означает, что приватность сама по себе не доказывает преимущество. Сохранённые замеры 0.6 на одном POCO показывали большой разрыв Lite/Standard, но не заменяют текущие Samsung-замеры.

Пользователь утвердил рекомендацию по содержимому как предложение с кнопкой, объяснение уменьшения, iOS и полный GitHub workflow. Эвристика является гипотезой с безопасным универсальным вариантом и ручным выбором. Поэтому Conditional-Go касается этой доработки; утверждение о рыночной конкурентоспособности остаётся непроверенным.
